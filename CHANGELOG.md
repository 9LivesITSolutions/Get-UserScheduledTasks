# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.1.4] - 2026-10-05

### Added
- `-NoisePattern` and `-IncludeNoise` parameters: tasks generated by Windows or installers (`User_Feed_Synchronization`, `Optimize Start Menu Cache Files`, `CreateExplorerShellUnelevatedTask`) are hidden by default; the match is made on the start of the task name so GUID/SID suffixes are covered.

## [1.1.3] - 2026-10-05

### Added
- `ErreurLecture` flag, filter option and legend entry for tasks that are found but cannot be read.

### Fixed
- A task whose definition raised an error during collection was silently dropped; each task is now processed in its own `try/catch` and reported with the error message in its description.

## [1.1.2] - 2026-10-05

### Changed
- The "unreachable servers" card and section are now "Erreurs de collecte" (collection errors) and report the originating server for errors raised inside the remote scriptblock.

### Fixed
- Vendor classification matched short terms anywhere in the task name (for example `HP` inside `HPRIM`, or `Oracle`), so custom tasks were hidden when filtering on "Custom". The pattern is now anchored on whole words and applied to the task path and author only.
- `Get-ScheduledTask` enumeration errors are no longer suppressed on the remote side.

## [1.1.1] - 2026-10-05

### Changed
- HTML report uses the full browser width; text columns are wider before truncation.

### Fixed
- `MotDePasseStocké` and `CompteNominatif+Highest` produced false positives for gMSA and machine accounts (name ending with `$`), built-in accounts (SYSTEM, LOCAL SERVICE, NETWORK SERVICE, `NT SERVICE\*`, detected by SID so detection is language independent) and tasks running as a group.
- `S4U` logon type is no longer flagged as a stored password; `InteractiveOrPassword` is now taken into account.

## [1.1.0] - 2026-10-05

### Changed
- HTML report redesigned as an interactive, standalone page in the 9 Lives audit theme: light theme, KPI cards acting as filters, flag legend, badges, sortable columns, full-text search, server/category/flag filters, expandable rows, filtered CSV export, collapsible collection-error section, branded footer.
- Report data is embedded as JSON and rendered client-side; the file stays self-contained and works offline.

## [1.0.1] - 2026-10-05

### Fixed
- Accented characters were corrupted in the HTML report. The page now declares `<meta charset="utf-8">` and the script is saved as UTF-8 with BOM with CRLF line endings, so Windows PowerShell 5.1 reads it correctly.

## [1.0.0] - 2026-10-05

### Added
- Inventory of scheduled tasks outside `\Microsoft\*` on Windows servers, queried in parallel through WinRM.
- Server list from Active Directory (`-SearchBase`) or supplied with `-ComputerName`; alternate credentials with `-Credential`.
- Per-task details: path, name, state, author, run-as account, logon type, run level, triggers, actions, last/next run, last result.
- Risk flags: stored password, named account with highest privileges, last run in error, disabled task.
- Vendor/custom classification with `-ExcludeVendor`.
- CSV export (`;` delimiter, UTF-8 with BOM), HTML report and per-server unreachable list.
